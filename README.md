Entry for the make.fun bounty [Make the AI judge feel curious](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311): a program that writes one short text to `/output/entry.txt`, written to intrigue the AI judge reading it.

## Run

```sh
node main.ts
```

The program writes one short text (166 characters, counted as Unicode code points) to `/output/entry.txt`. It is deterministic — the same bytes on every run — and uses no network.
